# آورا وی‌پی‌ان (AURA VPN)

یک کلاینت متن‌باز اندرویدی برای V2Ray و Xray با تمرکز بر پایداری تونل، حریم خصوصی و مسیریابی هوشمند ایران.

> وضعیت پروژه: شروع توسعه. این نسخه هنوز هسته VPN، تونل TUN یا مسیریابی عملیاتی ندارد و برای محافظت از ترافیک واقعی آماده نیست.

## اهداف
- اندروید با Kotlin، Jetpack Compose و Android VpnService
- اتصال هسته‌های Xray و sing-box از طریق لایه سازگاری
- واردکردن و اعتبارسنجی لینک‌ها و اشتراک‌های رایج
- مسیریابی اختیاری هوشمند ایران برای دامنه، IP، DNS و اپلیکیشن
- رابط فارسی راست‌چین با فونت محلی Vazirmatn
- ساخت و تست خودکار با GitHub Actions

## اصول توسعه
1. وضعیت اتصال فقط پس از سلامت واقعی هسته و رابط TUN نمایش داده شود.
2. اطلاعات ورود، کلید خصوصی و لینک اشتراک در گزارش‌ها ثبت نشوند.
3. نسخه هسته‌های بومی ثابت و مجوزهای آن‌ها پیش از انتشار بررسی شوند.
4. شناسه بسته اپلیکیشن‌ها پیش از افزودن به فهرست دورزدن، از منبع معتبر بررسی شود.
5. به‌روزرسانی قوانین جغرافیایی باید قابل بررسی و تأیید باشد.
