# AURA VPN design tokens

## Color
- Background: #0B1020
- Background elevated: #151D3B
- Surface: #17223B
- Primary electric cyan: #38C8FF
- Secondary indigo: #6675F5
- Connected: #28C982
- Connecting: #FFBF4A
- Error: #FF5B68
- Primary text: #F5F7FF
- Secondary text: #9CA9C7

## Shape and spacing
- Cards: 20–28dp radius
- Controls: minimum 48dp touch target
- Base spacing unit: 4dp
- Prefer subtle elevation and restrained glow over heavy shadows.

## Typography
Vazirmatn is the required bundled typeface for Persian and English. Font binaries and the upstream SIL Open Font License must be added before claiming the typography requirement complete. Do not fetch fonts at runtime.
